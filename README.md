# rental-app

Площадка аренды жилья на Java (Servlet + JSP, без Spring), по образцу Airbnb: пользователи выкладывают объявления, бронируют чужое жильё, после завершения брони оценивают друг друга.

## Возможности

- Регистрация/вход (пароли хранятся в виде PBKDF2-хеша с солью).
- Добавление и редактирование своих объявлений.
- Поиск жилья по городу, стране, диапазону цены.
- Бронирование жилья на даты.
- «Мои бронирования» - брони, которые сделал сам пользователь как арендатор: можно запросить отмену или изменение дат, после завершения - оценить владельца.
- «Брони на моё жильё» - брони на собственные объявления: владелец видит, кто и когда забронировал, подтверждает или отклоняет запросы на отмену/изменение дат.
- Рейтинг пользователей (среднее по полученным оценкам), автоблокировка при рейтинге ниже 2.0.

## Технологии

- Java 17, Servlet API 4.0, JSP, Maven
- MySQL (JDBC, без ORM — все запросы через `PreparedStatement`)
- Jetty (`jetty-maven-plugin`) как встроенный контейнер для разработки

## Настройка

1. Создайте базу и таблицы - выполните по порядку SQL-файлы из `src/main/java/com/example/dao/`: `create_db.sql`, `properties.sql`, `bookings.sql`.
2. Скопируйте [src/main/resources/db.properties.example](src/main/resources/db.properties.example) в `src/main/resources/db.properties` и впишите свои данные подключения к MySQL. Этот файл в `.gitignore` - пароль не попадёт в репозиторий.
3. Запустите:
   ```bash
   mvn jetty:run
   ```
   Приложение поднимется на `http://localhost:8080`.

## Структура

```
src/main/java/com/example/
  servlets/      все обработчики запросов
  dao/           доступ к БД (UserDAO, PropertyDAO, BookingDAO) + SQL-схема
  model/         модели данных
  utils/         DBConnection, PasswordUtils (хеширование паролей), HtmlUtils (экранирование вывода)
src/main/webapp/
  *.jsp              точки входа страниц (задают title/content и подключают layout.jsp)
  WEB-INF/*.jsp      сама разметка страниц, подключается через layout.jsp
  WEB-INF/web.xml
```
